# Project audit — 2026-10-13

This review started from `42da7d7` and produced the v0.4 corporate-floor and reliability changes. It covers first-party application code, the server, CLI, VS Code companion, test scripts, build/release configuration, public assets and documentation. Dependency versions and production packaging were reviewed separately. It is a tested improvement record, not a guarantee that every browser, provider version or future input is bug-free.

## Method

ECC supplied the architecture audit, design direction, team scope and verification checklists. Two independent implementers reviewed backend/packaging and UI/data flows; a third reviewer challenged the 3D changes. Each had a disjoint write scope or a read-only review contract. The main integration pass reviewed their changes and exercised the combined application. ECC hook execution, Full Harness and personal Codex configuration were outside this project audit; no personal Codex settings were modified.

The review traced task creation through validation, durable storage, provider launch, JSONL output, SSE, UI state and character presentation. Visual checks covered the office overview, inspected characters, walking, seating and coffee. Synthetic providers exercised failure paths without account usage. Fixtures and browser captures live in ignored `work/`, `screenshots/` and temporary data directories; public documentation images contain only synthetic demo content.

## Verification and artifacts

- `npm run verify:public`: public scan, lint, 64 behavior tests, nine UI/data regression groups, TypeScript/production build and server/CLI/companion syntax checks.
- `npm run smoke:browser`: mocked API browser flows, keyboard dialogs, errors/recovery, stale results, malformed storage, 20 locale options, Brazilian Portuguese, RTL and widths 320/390/768.
- `npm run smoke:floor`: passed isolated 0/1/4/20/100/1000-agent rendering, distant-agent focus, mobile overflow, rapid role edits, continuous same-geometry snapshots and reduced-motion checks. This matrix measures rendered correctness/WebGL availability, not a cross-hardware FPS guarantee.
- `npm run smoke:avatars`: passed actual moving samples (2.17 meters captured in the final run), seated/thinking poses, coffee arrival, mug capture and WebGL/console checks. Screenshots supplement assertions; the script does not claim mesh-level physical proof.
- `npm run smoke:roster`: passed isolated Live profile creation/edit/removal, persistence and 0/1/4/5/20/50/80-agent teams.
- `npm run smoke:demo`: public-demo build with simulated tasks and no API calls.
- Dependency scan found zero reported vulnerabilities for the locked dependency set at review time. The public-history pattern scan inspected 256 text objects reachable from main/tags, with zero detected private paths or matched token/private-directory patterns. Binary history was not OCR-scanned; pattern scans cannot recognize every possible secret format.

Local evidence includes `work/floor-audit-evidence.json`, `work/frontend-evidence.json`, `work/dependency-audit.json`, `work/history-audit.json`, `work/avatar-*.png`, `work/floor-*.png` and packaged artifacts. The ECC rendered-evidence checker passed; it validates evidence completeness, not screenshot correctness. The two public preview images were refreshed from isolated demo captures. Git hooks repeat verification before publishing; CI then repeats source/runtime checks on Linux and Windows.

## Practical limits

The office remains a functional local prototype. Profiles launch independent CLI jobs; seating hints, coffee and decorative boards do not implement delegation, shared memory or real conversation. Only recorded task events drive execution status.

Provider protocol fixtures cover Codex, Claude and Gemini, but an installed/authenticated provider and its external model/service must be tested separately. Claude's selected flags require a compatible current CLI; Gemini compatibility has not been established with a real authenticated run. Companion tests use a VS Code API harness; packing a VSIX does not prove successful use inside every actual editor version.

The API is unauthenticated and loopback-only. Workspace locks cover this instance, not external applications/other office instances. Normal descendant cancellation and coordinated shutdown are tested; power loss, forced termination and escaped POSIX process groups do not have an absolute guarantee. Task data is private local plaintext. Long-running SSE load and every browser/GPU combination were not benchmarked.

Collision assertions use the application's dimensions and bounding volumes. They are useful regressions, not a formal proof for every pose, orbit angle, concurrent operation or future prop. Screen-reader review, native-speaker translation review and additional real provider/editor testing remain separate acceptance work.
